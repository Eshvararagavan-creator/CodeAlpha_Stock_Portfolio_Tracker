# CodeAlpha Stock Portfolio Tracker

A console-based stock tracker for the CodeAlpha Python Programming Internship.

## Features

- Hardcoded sample stock prices for predictable practice
- Accepts stock symbols and quantities
- Calculates per-stock values and total investment
- Optionally exports a CSV report

## Run and test

```bash
python portfolio_tracker.py
python -m unittest discover -s tests -v
```

This educational project does not use live market data and is not investment advice.
